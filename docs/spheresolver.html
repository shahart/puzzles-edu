Write Your Own Puzzle

Coordinates use the same q,r,z layer notation as the hex solver, but neighboring layers are offset so every sphere has up to twelve touching neighbors.

Pyramid shorthand Start with #pyramid 4, immediately end the implicit grid, then define each piece with q,r,z triples.
Arbitrary grids Use #rows,columns,layers for layered ASCII or #coordinates for an explicit close-packed cell set.
Piece blocks Use #PieceA, optional xN identical copies, and finish with #piece-End.
Physical rotations Pieces can use up to 24 FCC-lattice rotations. Mirror-only copies are never introduced.

The browser harness covers parsing, FCC rotations, solving, and sphere placement.
