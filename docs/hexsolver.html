Write Your Own Puzzle

Axial coordinates are written as q,r,z. The six neighbors change q and r; front and back change z.

Axial ASCII Start with #rows,columns,layers. Use x for a cell, holes for -, and a blank line between layers.
Coordinate lists Start with #coordinates, then write one integer q,r,z triple per cell. Negative coordinates are valid.
Piece blocks Finish the grid with #end of grid. Define #PieceA blocks and finish with #piece-End. Add xN to create identical copies.
Physical turns Pieces may rotate in 60° steps and turn front-to-back, for up to 12 distinct orientations.
q,r +1,0 +1,-1 0,-1 -1,0 -1,+1 0,+1

The browser harness covers parsing, orientations, solving, and rendering.
